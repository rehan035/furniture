# Spike Wood Furniture Showroom — Islamabad

**Bespoke Solid Hardwood Joinery & Architectural Furniture Showcase**

An editorial digital showroom for **Spike Wood Furniture Showroom (Islamabad, Pakistan)** crafted with the **Warm Editorial Timber** design system (`Playfair Display` + `Plus Jakarta Sans`, warm ivory `#FBF9F6` canvas, rich walnut `#4A3525` & `#322011` accents).

---

## Key Features

- **Grand Architectural Hero Showcase**: Centerpiece living & dining room vignette with timber species, artisan joinery, and private viewing scheduling.
- **Curated Furniture Collections**: Interactive filtering across 6 bespoke categories (*Living*, *Dining*, *Bedroom*, *Storage & Consoles*, *Study & Library*) with detailed joinery specifications and custom dimension modals.
- **Seasoned Hardwood Finish Comparison**: Interactive material comparison bar for *American Dark Walnut*, *Burmese & Golden Teak*, *Seasoned Rosewood (Sheesham)*, and *Quarter-Sawn White Oak* with equilibrium moisture metrics.
- **Honest Joinery & Workshop Heritage**: Highlights kiln-dried hardwood conditioning, hand-cut dovetail & blind mortise joinery, and micro-porous matte organic wax finishes.
- **Showroom Locator & Direct WhatsApp Concierge**: Verified Islamabad showroom timings, Google Maps directions, and an interactive bespoke inquiry builder connected to `+92 300 506339`.

---

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`)
- **Typography**: `Playfair Display` (editorial serif headings) & `Plus Jakarta Sans` (body & architectural catalog metadata)

---

## Getting Started Locally

```bash
# 1. Install dependencies
npm install

# 2. Start the development server (runs on port 3000)
npm run dev

# 3. Build for production
npm run build
```

### Option 1: Using the AI Studio Top Bar
Click the **GitHub** icon in the top navigation bar of Google AI Studio to export and push this repository directly to your GitHub account.

This workspace is already initialized as a Git repository with all files committed on the `main` branch:

